## 4. 8 项整改逐项裁决

### M-2 Commander Push/Apply 独占 — **CLOSED（含一处验收方修复）**
- Application（config_apply.py）独占：push 乐观锁 CAS（lock 内 `expected_revision` 比对）、`asyncio.shield` 事务、durable commit 先于 reload、结果裁决与 `config_failed` 记账、BLOCKED/APPLIED 判定。
- Infrastructure（snapshots.py）仅 Proto 映射与存储 I/O（候选暂存、校验、提交）。
- **缺陷（验收方修复）**：a7d04e8f5 重构把 `_validate_unique_connections(snapshot)` 调用行与 `async def push(` 定义行拼接成 `_validate_unique_conn    async def push(`，产生 snapshots.py:322 语法错误，同时静默丢失 push 时唯一连接校验。已修复（e05ec030f）。该拼接产物未被 ChatGPT 任何静态门禁发现（compileall/ruff/mypy 全红才能暴露，上一轮未跑）。
- 测试：tests/commander 21 项 Push/Apply 专项 + 系统级全绿。

### S-4 Domain/Infrastructure 配置分层 — **CLOSED**
- Domain（domain/config.py）仅业务不变量；技术 Schema（grpc/security/nats/metrics/shutdown/顶层键集）隔离于 infrastructure/config_schema.py。
- 磁盘与 RPC 双入口同链：`read_snapshot` 收敛到 `validate_snapshot`（config_io.py:129），wire 路径 `snapshot_from_wire` 同一校验（含 size/sha256 先验）。
- 测试：strict config keys 套件按归属迁移后 27 项全绿（原 9 项失败为归属钉错层）。

### S-7 Web Server Delivery 化 — **CLOSED**
- 生产代码零旧 RPC 残留（ListSinks/GetSinkStatus/Start/Stop/Restart/ClearSink 全仓 grep 零命中）。
- sink.py 走 `SinkServiceStub`（ListDeliveries/GetDelivery/StartDelivery/StopDelivery）+ mTLS 凭据环境变量 fail-closed；无明文通道。
- restart/clear：路由层 404 明确拒绝 + 应用层二重拒绝 + proto 无该 RPC（不可能绕过）。
- 陈旧破损测试（tests/system/recovery 引用已删 management_cli）已迁移（48447334e）。
- 小观察（非违规）：`GrpcClientBase` 的 insecure 分支存在但 sink.py 不走该基类；聚合层状态用字符串字面量（与 proto string 契约一致）。

### N-CLI-1 Collector 管理令牌 — **CLOSED**
- 服务端：`CollectorConfigRpc._authorize`（config_service.py:180-189）——未配置令牌 → PERMISSION_DENIED（fail-closed）；`hmac.compare_digest` 恒定时间比较；abort 消息静态无回显。
- 客户端：CLI runtime.py collector_admin_metadata、web_server collector.py `_admin_metadata` 均缺失即本地 PermissionError，不发匿名请求。
- 令牌泄漏面：`grpc.RpcError.str()` 不含 metadata；错误信封不含令牌；`tracing.py` 仅内存提取 traceparent。
- 严格 E2E 新增断言：正确令牌 start/stop/read 全通；错误令牌 → PERMISSION_DENIED；缺失 → 本地拒绝且零 RPC 上送；令牌不出现在 stdout/JSON/审计日志/六服务 systemd 日志（收尾全文扫描）。
- 豁免集（GetServiceInfo/Status/Capabilities/GetMetrics/ListDevices 等只读 RPC）与设计文档 v1_40 矩阵一致。

### G-P2-1 TargetLeaseRegistry 移除 — **CLOSED（测试半边由验收方迁移）**
- src 零残留；VariableLeases 唯一权威（runtime.py:95 唯一实例化），gRPC 适配器仅转换不裁决；principal 绑定围栏、TTL 界限、invalidate 语义与设计 v1_42 一致。
